# 🎮 Rock Paper Scissors Game

## 📖 About

This is a classic Rock Paper Scissors game implemented with HTML, CSS, and JavaScript. Challenge the computer to a match and see who comes out victorious!

## 🎯 How to Play

1. Open the `index.html` file in your web browser
2. Click on one of the three options: Rock, Paper, or Scissors
3. The computer will randomly select its option
4. The winner is determined according to the rules below

## 📏 Game Rules

| Move        | Beats       |
| ----------- | ----------- |
| 🪨 Rock     | ✂️ Scissors |
| 📄 Paper    | 🪨 Rock     |
| ✂️ Scissors | 📄 Paper    |

### Rule Explanation:

- **Rock** crushes **Scissors** → Rock wins
- **Paper** covers **Rock** → Paper wins
- **Scissors** cut **Paper** → Scissors wins
- If both players choose the same option → It's a tie!
